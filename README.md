# mood_BCI — 情绪脑电采集与跨被试同步

64 通道脑电采集（ADS1299 / OpenBCI 兼容板）→ 实时看波形 → 算情绪（效价 + 唤醒度）→ 测多人跨被试同步（ISC）。**拿到硬件 + 下载软件，几步就能上手**，Windows / macOS 都能用。

---

## 🚀 新手 5 分钟上手（Windows）

> 📄 **发给用户看的部署指南**：见 **[`Windows部署指南.md`](Windows部署指南.md)** —— 拿到硬件前先做的 3 件事（下载/装驱动/验证打开），照着做，硬件一到手插上就能测。

### 1. 下载

到右侧 **Releases** 下载最新的 `eegscope-windows.zip`，**解压**到任意文件夹（路径尽量别带中文和空格）。

### 2. 装驱动（一次性，每台电脑装一次）

把采集板用 USB 插上电脑。第一次插会显示"未知设备"，需要装一次 STM32 虚拟串口驱动，板子才会变成 `COM3 / COM4 / …`。

- 解压后的文件夹里若有 `drivers/` 里的 `.exe`，双击装上即可。
- 若没有，去 ST 官网下载 **STM32 Virtual COM Port Driver**（包名 STSW-STM32102，需注册登录），装一下即可：
  https://www.st.com/en/development-tools/stsw-stm32102.html

> macOS / Linux 系统自带驱动，不用装。

### 3. 运行

双击 `eegscope.exe`（或 `start.bat`），打开启动器，点「**🔧 调试向导**」，跟着三步走：

1. **检测板子** —— 自动扫描，告诉你几块板、哪些电极没贴好
2. **摸电极识板** —— 按提示捏电极，自动把串口填好（不用手改文件）
3. **启动采集** —— 出波形，看质量面板大多绿色就成了

**情绪指标**（效价 FAA、唤醒度）在右侧面板实时显示。要看准情绪，先让被试**闭眼静坐 1–2 分钟**（alpha 波闭眼才明显）。

## 🔑 关键硬件背景

- 16 通道 ADS1299（RT-BCI EXP-8CH，OpenBCI 兼容，STM32 CDC 串口），4 块级联 = 64 通道
- RLD = 地，REF = 参考；帧协议 0xA0/0xC0，16ch = 125Hz
