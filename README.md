# mood_BCI（情绪脑电采集与同步）

多通道脑电采集（ADS1299 / OpenBCI 兼容板）→ 实时可视化 → 情绪分析 / 跨被试同步（inter-brain 同步 ISC）。创业方向：团建/协作场景的脑电同步测量。

## 上手必读（按顺序）

1. **`HARNESS.md`** — 不可违背的产品设计约束（改动前必读）
2. **`设备接入Mac_一条龙指南.md`** — 板子到手后如何接线、装驱动、跑通采集
3. **`software/README.md`** — 采集软件（eegscope）说明

## 目录结构

| 目录 | 内容 |
|---|---|
| `software/` | 采集软件：实时脑电可视化 + 情绪分析桌面应用（eegscope）+ 脚本 |
| `research/` | 调研：DEAP 情绪识别、微针电极（免涂抹）、知识库索引、神经影像学 |
| `RT-BCI产品资料包/` | RT-BCI 硬件板官方资料（通信协议、原理图、连接方式、使用说明） |

## 关键硬件背景（见 HARNESS.md 详情）

- 16 通道 ADS1299（RT-BCI EXP-8CH，OpenBCI 兼容，STM32 CDC 串口）
- RLD = 地，REF = 参考；弹针干电极
- 帧协议 0xA0/0xC0，16ch = 125Hz
