# 硬件前期验证指南（64ch 帽 + 16ch ADS1299 + 3 弹针）

> 目的：拿到设备后，按本文一步步接电脑、跑通「电极 → ADS1299 → 串口 → eegscope → 分析算法」的完整链路。
> 软件已全部就绪，本指南只讲「怎么接、怎么配、怎么测」。

---

## 一、硬件清单与定位

| 硬件 | 数量 | 作用 | 前期验证用它测什么 |
|---|---|---|---|
| 64 通道脑电帽 | 1 | 电极物理位置（10-10 布局） | 电极定位、戴帽贴合 |
| 16 通道 ADS1299 板 | 1 | 采集（2 颗 ADS1299 级联，OpenBCI 兼容） | 采集链路、信号质量 |
| 弹针电极（干电极） | 3 | 免涂抹电极 | 免涂抹能否采到信号（阻抗） |

**关键理解**：帽子有 64 个电极位，但 ADS1299 只能采 16 通道。前期验证 = 用 16 通道接帽子里的 **16 个核心电极**，先跑通链路，不追求一次上 64 通道。

## 二、前期验证的 16 个通道（从 64ch 帽子里选）

选这 16 个，是因为它同时覆盖情绪测量和 SSVEP 两条线的核心导联：

| 用途 | 通道 |
|---|---|
| 情绪测量（FAA 需要 F3/F4） | Fp1、Fp2、F3、F4、F7、F8 |
| 中线 ERP（产品反馈场景） | Fz、Cz、Pz |
| 运动/中央区 | C3、C4 |
| 颞叶（情绪 ISC） | T7、T8 |
| 枕区（SSVEP 用） | O1、O2、Oz |

即 `config.yaml` 里现有的默认 16 通道：`Fp1 Fp2 F3 F4 F7 F8 Fz Cz C3 C4 T7 T8 Pz O1 O2 Oz`。

> 参考/地电极（BIAS/DRL + SRB2）按 ADS1299 板子标注单独接，不占这 16 个采集通道。弹针场景见 §四。

## 三、接电脑测试步骤（按顺序）

### 第 1 步：抓原始字节，确认板子协议
克隆板波特率/帧格式/通道数可能跟 OpenBCI 原版有出入，**先抓字节、别瞎猜**：
```bash
cd ~/mood_BCI/software
env -i HOME=$HOME PATH=/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin PYTHONPATH= \
  .venv/bin/python scripts/capture_serial.py
```
确认三件事再往下走：① 波特率（标准 115200）；② 帧头 0xA0；③ 通道数（8 还是 16 = Daisy）。

### 第 2 步：填 config.yaml
把 `source.type` 改成 `openbci`，填抓字节确认的：
```yaml
source:
  type: openbci
  openbci:
    port: "/dev/cu.usbserial-XXXX"   # capture_serial 会列出
    baudrate: 115200
    n_channels: 16                   # 8 或 16
    gain: 24.0
```

### 第 3 步：跑 eegscope 看实时波形
```bash
env -i HOME=$HOME PATH=/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin PYTHONPATH= \
  .venv/bin/python main.py
```
看四件事：波形有没有正常滚动、频谱有没有 alpha 峰（闭眼升高）、信号质量面板有没有标红、枕区通道有没有明显 50Hz（有就查接地/DRL）。

### 第 4 步：跑分析算法（链路自检通过后）
- **SSVEP**（高小榕算法）：`scripts/analyze_ssvep.py <session.npz> --freqs 8.0,9.0,10.0,11.0,12.0`
- **情绪指标**：`scripts/analyze_session.py <session.npz>`
- **链路自检**：睁眼/闭眼 alpha 差异（测不到 = 链路断，别谈情绪，先查电极阻抗）。

## 四、弹针电极（3 个）怎么测

弹针是干电极（免涂抹），前期用它验证「免涂抹能否采到可用信号」。3 个弹针 = 2 个 EEG + 1 个参考（或 3 个 EEG），改 config 的 `channels` 即可：
```yaml
channels: ["F3", "C3", "REF"]   # 2 EEG + 1 参考，FAA 会自动降级
```
测试要点：
- 弹针是「点接触」，阻抗远高于湿电极，**上电先看信号质量面板的阻抗/平线/饱和**，贴不紧就全红。
- 弹针测不了 SSVEP 的微弱枕区响应（除非贴枕区），主要验证额叶 F3/F4 的 alpha 和 FAA。
- 结论判据：弹针采到的 alpha 睁闭眼差异 ≥ 湿电极的 2 倍以内，就说明干电极可用；差太多说明要换弹针材质/加大压力。
