# 现有录制的 25 Hz 复核与下一步（2026-11-19）

## 结论

1. 目前证据最支持「设备与电脑/环境的耦合会显著改变 25 Hz 干扰」，但不能仅凭距离变化断定干扰来自 USB、显示器、接地或电极接触。
2. 20:19:53 录制中 25 Hz 是全通道共同的强窄带成分；当前源码离线重滤后与文件保存的 `filtered` 高度一致，但干扰仍占滤后信号的主要部分。滤波器确实执行了，只是不能把这个强成分滤到足以证明 EEG 干净。
3. 20:38:30 录制中的共同 25 Hz 成分明显较弱，源码离线重滤与保存结果同样一致；PO4 仍有较突出的局部 25 Hz 能量。同步统计未见帧丢失或采样缺口，因此现有证据不支持把主问题归因于串流掉帧。
4. 该软件的 25 Hz 陷波会同时削弱真实 EEG 的 25 Hz 附近成分。原始数据必须保留；`filtered` 只用于查看/辅助分析，不能被当作「已恢复干净脑电」的证明。

## 复核方法

- 对象：`20261119_193730`、`20261119_195920`、`20261119_201953`、`20261119_203830` 的本地 `session.npz` 与 `sync.json`。
- 采样率均为 125 Hz、16 通道。用应用源码 `eegscope.dsp.SignalChain(125, (0.5, 45), (50, 25), 30)` 对 `raw` 整段离线重滤，并与同一 NPZ 中的 `filtered` 比较。
- 同一信号质量口径：2 秒窗、1 秒步进；Welch 1 秒窗（频率分辨率约 1 Hz）；计算每通道 24–26 Hz 功率占 1–45 Hz 总功率比例。达到「至少一半有效通道比例 >50%」时记为预警。这是软件启发式，不是电极阻抗或噪声源诊断。
- 为检查峰值另对 20:19:53 与 20:38:30 整段使用 4 秒 Welch 窗（约 0.25 Hz 分辨率）。

### 滤波器核验

- 20:19:53：源码重滤与已保存 `filtered` 的逐通道相关系数中位数约 0.99985；两者几乎一致。原始 25 Hz 相对功率中位数约 99%，滤后仍约 77%（4 秒 Welch 口径）。这不是滤波代码未运行的证据，而是原始强干扰滤后仍然压过其他频段。
- 20:38:30：重滤与已保存 `filtered` 的相关系数中位数约 0.99996；原始 25 Hz 相对功率中位数约 4.9%，滤后约 0.17%。滤波器在该次记录上有效压低了窄带成分。
- 20:19:53 与 20:38:30 元数据都记录了 25 Hz notch 配置。结果差异与原始干扰强度差异一致，暂不支持「后一次只是软件配置才生效」的解释。

不同窗口长度会改变功率比例和预警数量；上表只用于同一口径下的相对比较，不能与旧报告中采用其他窗口/带宽的数字直接混用。

## 下一步（先不改固件、不重复折腾接线）

1. 把约 1.1 m 的设备—主机间距和绝缘支架保留为后续的环境基准；不要为了消除 25 Hz 把电极端接到 USB GND、RLD 或其他未知节点。
2. **目前暂停佩戴复测。**仓库中的 V1.5 原理图显示 USB-C GND、USB 转串口地与板上 GND 直连，未见 USB 数据隔离器/隔离电源；板上电池不能证明 USB 接电脑后的整套系统具备人体隔离。先按硬件排查记录第 12 节完成系统级隔离/漏电流核验。
3. 隔离未确认期间，只做不佩戴的离体/桌面软件检查；不要把结果解释成 EEG 链路的安全或性能验证。确认系统级隔离后，再保持其余接线/摆位不变，进行 30–60 秒短复核并保存 raw、filtered、meta、sync。
4. 未来复核通过条件仍只是工程筛查：原始 25 Hz 预警窗比例低于 10%，无饱和通道、无持续同步缺口，并单独检查 PO4；即使通过，也只说明该次环境下干扰较低，不能称为干净 EEG。若原始预警仍高而滤后低，保留原始数据，不以陷波结果宣称干净；若只有 PO4 异常，优先排查该电极及对应板端连接。

## 限制

- 四次录制不是随机化、重复多次的受控实验。已知 20:19:53 和 20:38:30 的距离差与 25 Hz 变化同时出现，提示距离值得固定，但还不能证明距离是唯一原因。
- 25 Hz 预警只是波形指标；没有同步硬件阻抗、示波器或独立电源/接地测量，不能判定噪声耦合路径。
- 当前记录不能证明电极接触、参考拓扑或四板 REF 接线完全正确，也不能据此给情绪解码有效性背书。
